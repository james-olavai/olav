### 1.1. query_database 工具标准化 (快速赢家 🏆)

**文件**: `.olav/shared/tools/query_database.py`

**当前代码** (35-70 行):
```python
def main(params: dict) -> dict:
    sql = params.get("sql")

    if not sql:
        return {"error": "Missing 'sql' parameter", "status": "failed"}

    try:
        results = db_query(sql)
        return {
            "data": results,
            "count": len(results),
            "status": "success",
        }
    except Exception as e:
        error_msg = str(e)
        if "does not exist" in error_msg or "no such table" in error_msg.lower():
            return {
                "error": error_msg,
                "error_type": "missing_view",
                "suggestion": "Use inspect_schema to check available tables.",
                "status": "failed",
            }
        return {"error": error_msg, "error_type": "database_error", "status": "failed"}
```

**目标代码**:
```python
from pydantic import BaseModel, Field, validator

# 输入模型
class QueryDatabaseInput(BaseModel):
    """SQL 查询输入参数"""
    sql: str = Field(..., description="SQL query to execute", min_length=1)
    timeout: int = Field(default=30, description="Query timeout in seconds", ge=1, le=300)
    
    @validator('sql')
    def validate_sql_not_empty(cls, v):
        if not v.strip():
            raise ValueError("SQL command cannot be empty")
        return v

# 输出模型  
class QueryDatabaseOutput(BaseModel):
    """SQL 查询结果"""
    data: list[dict] | None = Field(None, description="Query result rows")
    count: int | None = Field(None, description="Number of rows returned")
    status: str = Field(..., description="Query status")
    error: str | None = Field(None, description="Error message if failed")
    error_type: str | None = Field(None, description="Type of error (missing_view, database_error)")
    suggestion: str | None = Field(None, description="Recovery suggestion")

def main(params: dict) -> dict:
    """Execute SQL query with automatic schema discovery."""
    # 参数验证 (Pydantic 自动执行)
    args = QueryDatabaseInput(**params)
    
    try:
        results = db_query(args.sql)
        output = QueryDatabaseOutput(
            data=results,
            count=len(results),
            status="success"
        )
    except Exception as e:
        error_msg = str(e)
        if "does not exist" in error_msg or "no such table" in error_msg.lower():
            output = QueryDatabaseOutput(
                status="failed",
                error=error_msg,
                error_type="missing_view",
                suggestion="Use inspect_schema to check available tables."
            )
        else:
            output = QueryDatabaseOutput(
                status="failed",
                error=error_msg,
                error_type="database_error"
            )
    
    return output.model_dump(exclude_none=True)
```

**优势**:
- ✅ 参数类型在代码中清晰定义
- ✅ 验证规则明确 (min_length, ge, le)
- ✅ 输出格式统一
- ✅ IDE 可以完全推断类型
- ✅ 减少 35 行代码 → 优化后只需 20 行

### 1.2. nornir_execute 工具标准化

**文件**: `.olav/shared/tools/nornir_execute.py`

**当前代码** (40-70 行):
```python
def main(params: dict) -> dict:
    device = params.get("device")
    command = params.get("command")
    timeout = params.get("timeout", 30)

    if not device:
        return {"error": "Missing 'device' parameter", "status": "failed"}
    if not command:
        return {"error": "Missing 'command' parameter", "status": "failed"}

    try:
        executor = get_executor()
        result = executor.execute(device=device, command=command, timeout=timeout)

        if result.success:
            return {
                "output": result.output or "",
                "device": device,
                "command": command,
                "status": "success",
            }
        else:
            return {
                "error": result.error or "Unknown error",
                "device": device,
                "command": command,
                "status": "failed",
            }
    except Exception as e:
        return {"error": str(e), "device": device, "status": "failed"}
```

**目标代码**:
```python
import re
from pydantic import BaseModel, Field, validator

class NornirExecuteInput(BaseModel):
    """Nornir 命令执行输入参数"""
    device: str = Field(..., description="Device hostname", max_length=100)
    command: str = Field(..., description="CLI command to execute", min_length=1)
    timeout: int = Field(default=30, description="Command timeout in seconds", ge=5, le=300)
    
    @validator('device')
    def validate_device_name(cls, v):
        # 允许的设备名称格式: 字母数字、下划线、短横线
        if not re.match(r'^[a-zA-Z0-9_-]+$', v):
            raise ValueError(f"Invalid device name: {v}")
        return v

class NornirExecuteOutput(BaseModel):
    """Nornir 命令执行结果"""
    output: str | None = Field(None, description="Command output")
    device: str = Field(..., description="Device name")
    command: str = Field(..., description="Command executed")
    status: str = Field(..., description="Execution status (success/failed)")
    error: str | None = Field(None, description="Error message if failed")

def main(params: dict) -> dict:
    """Execute CLI command on network device."""
    # 参数验证 (Pydantic 自动执行)
    args = NornirExecuteInput(**params)
    
    try:
        executor = get_executor()
        result = executor.execute(
            device=args.device, 
            command=args.command, 
            timeout=args.timeout
        )

        if result.success:
            output = NornirExecuteOutput(
                output=result.output or "",
                device=args.device,
                command=args.command,
                status="success"
            )
        else:
            output = NornirExecuteOutput(
                output=None,
                device=args.device,
                command=args.command,
                status="failed",
                error=result.error or "Unknown error"
            )
    except Exception as e:
        output = NornirExecuteOutput(
            output=None,
            device=args.device,
            command=args.command,
            status="failed",
            error=str(e)
        )
    
    return output.model_dump(exclude_none=True)
```

**优势**:
- ✅ 设备名称格式验证
- ✅ 参数范围验证 (timeout 5-300)
- ✅ 统一的输出格式
- ✅ 减少错误处理重复

### 2.1. 更新 query_database

**当前**:
```python
def main(params: dict) -> dict:
    args = QueryDatabaseInput(**params)
    # ...
```

**目标**:
```python
from langchain_core.tools import tool

@tool
def query_database(args: QueryDatabaseInput) -> dict:
    """Execute intelligent SQL query with automatic schema discovery.
    
    This tool allows the LLM to query the network database
    using natural SQL syntax.
    
    Args:
        args: Query parameters including SQL and timeout
    
    Returns:
        Query results or error information
    """
    # 不再需要 params 字典 - 直接使用类型化的 args
    try:
        results = db_query(args.sql)
        # ...
    except Exception as e:
        # ...
```

**变化**:
- ✅ 函数参数从 `params: dict` 变为 `args: QueryDatabaseInput`
- ✅ 返回类型更明确
- ✅ @tool 装饰器使其成为 LangChain Tool

## Task 3: @retry 装饰器添加 (1 天)

在 Task 2 完成后，为所有工具添加自动重试。

### 模式

```python
from tenacity import retry, stop_after_attempt, wait_exponential

@tool
@retry(
    stop=stop_after_attempt(3),
    wait=wait_exponential(multiplier=1, min=1, max=10),
    reraise=True
)
def my_tool(args: MyInput) -> dict:
    """My tool with automatic retry."""
    # 不需要 try-except 了！
    return do_something(args)
```

### 为什么？

- ❌ 现在: 每个工具都有自己的重试逻辑 (或没有)
- ✅ 目标: 统一的重试策略，所有工具自动受益

## 📝 风险缓解

### 风险 1: 向后兼容性破裂

**缓解**: 
- 保持旧 main() 函数支持一周
- 所有工具同时更新，无歧义

### 风险 2: Pydantic 验证过于严格

**缓解**:
- 使用 `coerce=True` 进行类型强制转换
- 使用 `Field(default=...)` 提供默认值

### 风险 3: 性能下降

**缓解**:
- Pydantic 验证开销 < 1ms
- @retry 和 @tool 装饰无运行时开销
