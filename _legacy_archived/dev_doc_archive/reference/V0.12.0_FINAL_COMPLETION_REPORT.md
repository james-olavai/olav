## 🔧 技术详情

### Pydantic 验证规则总结

**字符串验证**:
- min_length: 确保最小长度
- max_length: 限制最大长度
- 自定义 @validator: 格式检查 (如 IP 地址、设备名称)

**数字验证**:
- ge (>=): 最小值
- le (<=): 最大值
- 范围检查: 确保合理的超时时间

**可选字段**:
- Field(default=None): 允许缺失
- Field(...): 必需字段

### @tool 装饰功能

- 自动参数类型强制转换
- 参数验证错误处理
- LLM 工具发现和调用
- docstring 自动转换为工具描述

### @retry 重试策略

```
第 1 次尝试: 立即
失败 → 等待 2 秒
第 2 次尝试: +2 秒后
失败 → 等待 4 秒  
第 3 次尝试: +4 秒后
失败 → 返回错误
```

**最大总等待时间**: ~6 秒  
**适用场景**: 网络波动、短暂连接问题
