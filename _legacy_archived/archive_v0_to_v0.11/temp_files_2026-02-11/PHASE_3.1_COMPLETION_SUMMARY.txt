Cache Architecture (Phase 3.1):
┌────────────────────────────────────────────────────────────────────┐
│                                                                    │
│  query_database(sql, params)                                       │
│  ├─ get_query_cache() → Singleton factory                         │
│  │  └─ Thread-safe (double-checked locking)                       │
│  │                                                                │
│  ├─ cache.get(sql, context)                                      │
│  │  ├─ L1: Memory (OrderedDict LRU, 100 entries)                 │
│  │  └─ L2: Disk (SQLite, query_result_cache.db)                  │
│  │     └─ Cache HIT → Return immediately ✨                      │
│  │                                                                │
│  ├─ DataGateway.query_main(sql, params)                           │
│  │  └─ Cache MISS → Execute SQL                                  │
│  │                                                                │
│  └─ cache.set(sql, result, context, ttl_seconds)                 │
│     └─ Write to L1 + L2 for future hits                          │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘
