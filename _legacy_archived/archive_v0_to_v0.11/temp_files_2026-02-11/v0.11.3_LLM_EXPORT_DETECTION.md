## 💡 Implementation (1 Line in SKILL.md)

### SKILL.md Update
Added to system prompt in `.olav/skills/orchestrator/SKILL.md`:

```markdown
## File Export Detection (v0.11.2+)

If the user's query mentions exporting results to a file format 
(csv, json, markdown, yaml, txt, xml, pdf, xlsx, etc.):

1. **Detect the requested format** from the user query
2. **Extract the filename** if user specified one
3. **Include export markers in your response** using this format:
   - `<export_format>FORMAT</export_format>`
   - `<export_filename>FILENAME</export_filename>` (optional)

Examples:
- User: "列出所有设备，导出到csv"
  → Include: `<export_format>csv</export_format>`

- User: "列表导出为my_devices.json"
  → Include: `<export_format>json</export_format>`
  → Include: `<export_filename>my_devices</export_filename>`
```

### Orchestrator Update
In `orchestrate_query_sync()`:

```python
# Step 6: Parse export format markers (LLM-detected) ← FROM LLM RESPONSE
export_format = None
export_filename = None

format_pattern = r'<export_format>(\w+)</export_format>'
format_match = re.search(format_pattern, response_text)  # Parse LLM response
if format_match:
    export_format = format_match.group(1).lower()

filename_pattern = r'<export_filename>([a-zA-Z0-9_\-\u4e00-\u9fff]+)</export_filename>'
filename_match = re.search(filename_pattern, response_text)
if filename_match:
    export_filename = filename_match.group(1).strip()

# Step 7: Handle file export if LLM detected it
if export_format and query_result:
    export_result = format_and_export.invoke({...})
```

## 🌟 Advantages of LLM Approach

| Aspect | Hardcoded | LLM-Based |
|--------|-----------|-----------|
| **Flexibility** | Limited to predefined formats | Any format LLM understands |
| **Maintenance** | Update function code | Update SKILL.md prompt |
| **Extensibility** | Add new regex patterns | Add one example in SKILL.md |
| **Accuracy** | Keyword matching errors | Natural language understanding |
| **Cost** | Negligible | Use existing LLM call |
| **Robustness** | Fails on variations | Understands variations |
