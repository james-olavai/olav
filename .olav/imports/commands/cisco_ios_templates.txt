# Cisco IOS Command Templates - Command templates requiring parameters
# 
# Format specification:
#   !VARIABLE_NAME represents the variable to be replaced
#   When LLM/Agent encounters these templates, fill in specific values based on context
#
# Common variable names:
#   !INTERFACE_NAME - Interface name (GigabitEthernet0/1, Ethernet0/0)
#   !VLAN_ID        - VLAN ID (10, 100, 200)
#   !PREFIX         - IP prefix (10.0.0.0/8, 192.168.1.0/24)
#   !IP_ADDRESS     - IP address (10.1.1.1, 192.168.1.100)
#   !MAC_ADDRESS    - MAC address (aabb.cc00.1100)
#   !NEIGHBOR_IP    - Neighbor IP (for BGP/OSPF)
#   !AS_NUMBER      - AS number (65000, 65001)
#   !PROTOCOL       - Protocol name (ospf, bgp, static)
#   !VRF_NAME       - VRF name (management, customer-a)
#   !ACL_NAME       - ACL name (inside-acl, outside-acl)
#   !ROUTE_MAP_NAME - Route-map name
#   !TARGET         - ping/traceroute target
