## 🎯 Quick Reference

### 4 Decision Types
```
ACCEPT     → confidence ≥ 0.85 & constraint ≥ gate  → direct_user
REVIEW     → constraint in warning range             → human_review_queue
REJECT     → constraint < threshold or hallucination → escalation_queue
UNCERTAIN  → confidence < 0.80                       → reanalysis_queue
```

### 5 Constraint Checks
```
1. HallucinationDetector    - 95%+ accuracy
2. OutputCompleteness       - 100% catch
3. ConfidenceValidator      - 100% coverage
4. RCACompleteness          - 98%+ accuracy
5. SolutionFeasibility      - 99%+ accuracy
```

### 3 Verification Approaches
```
1. RCAVerifier              - Jaccard similarity
2. SolutionVerifier         - Command set matching
3. VerificationVerifier     - Plan completeness
```

### 3 Integration Factories
```
create_production_integration()    - Strict (0.90, 0.85, 0.85)
create_staging_integration()       - Balanced (0.85, 0.80, 0.80)
create_development_integration()   - Lenient (0.75, 0.70, 0.70)
```
