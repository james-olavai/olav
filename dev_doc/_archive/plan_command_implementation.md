# /plan 命令实现方案 (2026-02-06)

## 🎯 目标

实现`/plan`命令，让Orchestrator在执行前先规划任务，展示给用户确认后再执行。

**用户场景示例：**
```bash
OLAV> /plan 同步网络数据库和netbox中的数据

# Orchestrator输出：
## 同步计划（待确认）

### 第1步：数据发现阶段
- 调用netbox SubAgent："你有哪些数据表要同步？"
- 调用query SubAgent："你有这些数据表吗？"

### 第2步：数据对齐分析
- 对比两边的表结构和字段
- 生成差异报告

### 第3步：同步执行顺序
1. 同步interfaces（优先级：高）
2. 同步vlans（依赖interfaces）
3. 同步devices（基础数据）
4. 同步ip_addresses（依赖interfaces）

### 第4步：数据验证
- 同步后验证数据一致性
- 生成最终报告

是否执行此计划？[Y/n/edit]
```

DeepAgents的首句描述：
> Popular agents such as Claude Code and Manus use some common principles to address these challenges, including **planning (prior to task execution)**, computer access, and sub-agent delegation.

|------|--------|------|

| `checkpointer` | LangGraph | 保存状态，支持恢复执行 |
| `system_prompt` | create_deep_agent | 指导Agent先规划后执行 |

## 🏗️ 实现方案

### 方案A：System Prompt引导（⭐ 推荐，零代码改动）

**核心思路：** 通过System Prompt告诉Orchestrator"遇到`/plan`命令时，先规划后执行"

**实现步骤：**

#### 1. 更新Orchestrator System Prompt

```python
# src/olav/agents/orchestrator.py

PLANNING_MODE_PROMPT = """
## Planning Mode (/plan command)

When user starts with '/plan', enter Planning Mode:

**Phase 1: Information Gathering**
1. Identify required SubAgents for this task
2. Call each SubAgent to gather necessary information
   Example: 
   - task(netbox, "List all data tables you manage")
   - task(query, "Check if these tables exist in network database")

**Phase 2: Create Execution Plan**
1. Use write_todos() to create structured task list
2. Define task order, dependencies, and priorities
3. Include validation steps

**Phase 3: Present Plan to User**
1. Display the complete plan in Markdown format
2. Show:
   - Discovery steps (already completed)
   - Execution order with dependencies
   - Estimated impact and risks
3. Wait for user confirmation (automatic HITL pause)

**Phase 4: Execute Plan**
1. Execute tasks in order according to write_todos
2. Update todo status after each step
3. Generate final report

Example Plan Format:
'''markdown
## Synchronization Plan

### Discovery (Completed ✅)
- NetBox tables: devices, interfaces, vlans, ip_addresses
- Network database: devices, interfaces, vlans exist ✅

### Execution Order
1. **Sync interfaces** (Priority: High)
   - Reason: Foundation for other data
   - Estimated time: 5 minutes
   
2. **Sync vlans** (Depends on: interfaces)
   - Reason: Required by ip_addresses
   - Estimated time: 2 minutes

3. **Sync devices** (Priority: Medium)
   - Reason: Base entity data
   - Estimated time: 3 minutes

### Risks
- ⚠️ Interface sync may affect 100+ devices
- ⚠️ Rollback plan: restore from snapshot

Confirm execution? [Y/n/edit]
'''

IMPORTANT: Do NOT execute anything until user confirms.
"""

def load_orchestrator_prompt():
    """Load orchestrator system prompt with planning mode support."""
    base_prompt = load_skill_prompt("orchestrator")
    return base_prompt + "\n\n" + PLANNING_MODE_PROMPT
```

# src/olav/cli/cli_main.py

async def handle_plan_confirmation(plan_text: str) -> str:
    """Handle user confirmation for plan execution.
    
    Args:
        plan_text: The plan generated by Orchestrator
        
    Returns:
        "execute" - User confirmed to execute
        "cancel" - User cancelled
        "edit" - User wants to modify plan
    """
    print("\n" + "=" * 80)
    print(plan_text)
    print("=" * 80 + "\n")
    
    while True:
        response = input("Confirm execution? [Y/n/edit]: ").strip().lower()
        
        if response in ["y", "yes", ""]:
            return "execute"
        elif response in ["n", "no"]:
            return "cancel"
        elif response == "edit":
            print("\n💡 Tip: Provide modification requirements, e.g.:")
            print("  'Skip vlan sync' or 'Change order: devices first'")
            modification = input("Modification: ").strip()
            return f"edit:{modification}"
        else:
            print("Invalid input. Please enter Y/n/edit")

async def run_interactive_loop_async(session, agent, ...):
    """Run interactive loop with /plan command support."""
    
    while True:
        user_input = await session.prompt_async("OLAV> ")

        # Normal query processing
        ...

#### 3. Planning Workflow实现

```python
# src/olav/agents/planning_orchestrator.py

class PlanningOrchestrator:
    """Orchestrator with explicit planning phase."""
    
    async def plan_and_execute(self, user_query: str) -> dict:
        """Execute query with planning phase.
        
        Phase 1: Discovery
        Phase 2: Planning
        Phase 3: Confirmation
        Phase 4: Execution
        """
        
        # Phase 1: Discovery
        print("🔍 Phase 1: Information Discovery...")
        discovery_results = await self._discovery_phase(user_query)
        
        # Phase 2: Create Plan
        print("📋 Phase 2: Creating Execution Plan...")
        plan = await self._create_plan(user_query, discovery_results)
        
        # Phase 3: User Confirmation (HITL)
        print("✋ Phase 3: Awaiting Confirmation...")
        plan_display = self._format_plan_for_display(plan)
        
        confirmed = await self._confirm_plan(plan_display)
        if not confirmed:
            return {"status": "cancelled", "message": "Plan execution cancelled by user"}
        
        # Phase 4: Execute
        print("🚀 Phase 4: Executing Plan...")
        result = await self._execute_plan(plan)
        
        return result
    
    async def _discovery_phase(self, query: str) -> dict:
        """Gather information from relevant SubAgents."""
        # Example: NetBox sync scenario
        netbox_info = await task("netbox", "List all data tables you manage")
        query_info = await task("query", "List available tables in network database")
        
        return {
            "netbox_tables": netbox_info,
            "network_tables": query_info,
        }
    
    async def _create_plan(self, query: str, discovery: dict) -> dict:
        """Generate execution plan using TodoList."""
        # Use write_todos to create structured plan
        todos = [
            {
                "id": 1,
                "task": "Sync interfaces (high priority)",
                "status": "pending",
                "estimated_time": "5 minutes",
                "dependencies": [],
            },
            {
                "id": 2,
                "task": "Sync vlans",
                "status": "pending",
                "estimated_time": "2 minutes",
                "dependencies": [1],  # Depends on interfaces
            },
            {
                "id": 3,
                "task": "Sync devices",
                "status": "pending",
                "estimated_time": "3 minutes",
                "dependencies": [],
            },
            {
                "id": 4,
                "task": "Verify data consistency",
                "status": "pending",
                "estimated_time": "1 minute",
                "dependencies": [1, 2, 3],
            },
        ]
        
        # Write todos to agent state
        write_todos(todos)
        
        return {
            "todos": todos,
            "discovery": discovery,
            "execution_order": self._topological_sort(todos),
        }
    
    def _format_plan_for_display(self, plan: dict) -> str:
        """Format plan as Markdown for user review."""
        output = ["## Execution Plan\n"]
        
        output.append("### Discovery Results")
        output.append(f"- NetBox tables: {', '.join(plan['discovery']['netbox_tables'])}")
        output.append(f"- Network tables: {', '.join(plan['discovery']['network_tables'])}\n")
        
        output.append("### Execution Order")
        for step_num, todo in enumerate(plan['execution_order'], 1):
            output.append(f"\n**{step_num}. {todo['task']}**")
            output.append(f"   - Estimated time: {todo['estimated_time']}")
            if todo['dependencies']:
                deps = [f"Step {d}" for d in todo['dependencies']]
                output.append(f"   - Depends on: {', '.join(deps)}")
        
        output.append("\n### Risks")
        output.append("- ⚠️ This operation will modify NetBox database")
        output.append("- ⚠️ Estimated total time: 11 minutes")
        
        return "\n".join(output)
    
    async def _confirm_plan(self, plan_display: str) -> bool:
        """Display plan and wait for user confirmation."""
        print("\n" + "=" * 80)
        print(plan_display)
        print("=" * 80 + "\n")
        
        # Use HITL mechanism
        response = input("Execute this plan? [Y/n]: ").strip().lower()
        return response in ["y", "yes", ""]
    
    async def _execute_plan(self, plan: dict) -> dict:
        """Execute plan step by step."""
        results = []
        todos = plan['todos']
        
        for todo in plan['execution_order']:
            print(f"\n✨ Executing: {todo['task']}...")
            
            # Update todo status to in-progress
            todo['status'] = 'in-progress'
            write_todos(todos)
            
            # Execute the task
            result = await self._execute_task(todo)
            results.append(result)
            
            # Update todo status to completed
            todo['status'] = 'completed'
            write_todos(todos)
            
            print(f"✅ Completed: {todo['task']}")
        
        return {
            "status": "completed",
            "results": results,
            "plan": plan,
        }
    
    async def _execute_task(self, todo: dict) -> dict:
        """Execute a single task from the plan."""
        # Map task to actual SubAgent calls
        if "interfaces" in todo['task']:
            return await task("netbox", "Sync interfaces data")
        elif "vlans" in todo['task']:
            return await task("netbox", "Sync vlans data")
        # ... other tasks
    
    def _topological_sort(self, todos: list) -> list:
        """Sort todos by dependency order."""
        # Simple implementation: sort by dependencies
        sorted_todos = []
        remaining = todos.copy()
        
        while remaining:
            # Find todos with no unsatisfied dependencies
            ready = [
                t for t in remaining
                if all(dep in [s['id'] for s in sorted_todos] for dep in t.get('dependencies', []))
            ]
            
            if not ready:
                raise ValueError("Circular dependency detected in plan")
            
            sorted_todos.extend(ready)
            for t in ready:
                remaining.remove(t)
        
        return sorted_todos
```

### Orchestrator执行流程（Phase 1实现）

```python
# Orchestrator内部（System Prompt引导）

Step 1: 识别Planning Mode
    → 发现用户使用了/plan命令
    → 进入Planning Phase（不立即执行）

Step 2: Information Discovery
    → task(netbox, "你有哪些数据表要同步？")
    → NetBox返回：["devices", "interfaces", "vlans", "ip_addresses", "sites"]
    
    → task(query, "检查这些表是否存在：devices, interfaces, vlans, ip_addresses, sites")
    → Query返回：
        - devices: ✅ 存在
        - interfaces: ✅ 存在
        - vlans: ✅ 存在
        - ip_addresses: ❌ 不存在
        - sites: ❌ 不存在

Step 3: Create Plan
    → 分析：interfaces是基础数据，vlans依赖interfaces
    → 生成执行顺序：
        1. interfaces（优先级：高）
        2. vlans（依赖interfaces）
        3. devices（基础数据）
    → 排除：ip_addresses, sites（网络数据库不支持）

Step 4: Present Plan
    → 生成Markdown格式计划
    → 显示给用户

Step 5: Wait for Confirmation（HITL自动触发）
    → 等待用户输入 Y/n

Step 6: Execute Plan（用户确认后）
    → task(netbox, "同步interfaces数据", context={...})
    → task(netbox, "同步vlans数据", context={...})
    → task(netbox, "同步devices数据", context={...})
    → 生成最终报告
```
