# 设备表快速实施方案

## 问题回顾

测试中发现LLM生成了这样的SQL:
```sql
SELECT * FROM devices WHERE hostname IN ('R1', 'R2', 'R3', 'R4')
```

**错误**: devices表不存在，LLM"幻觉"出来的

**根本原因**: 没有明确的设备表，LLM不知道应该用什么数据源

---

## 快速解决方案

### 1️⃣ 建立devices表 (5分钟)

```python
# 在现有的DuckDB中建表
import duckdb
from pathlib import Path
from datetime import datetime

# 连接到语义缓存数据库
cache_db = Path(".olav/cache/semantic_cache.db")
conn = duckdb.connect(str(cache_db))

# 建表
conn.execute("""
CREATE TABLE IF NOT EXISTS devices (
    device_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    hostname VARCHAR(255) NOT NULL UNIQUE,
    ip_address VARCHAR(15) NOT NULL,
    device_type VARCHAR(50),  -- cisco_ios, juniper_junos
    vendor VARCHAR(50),        -- Cisco, Juniper, Arista
    model VARCHAR(100),        -- ISR4321, EX4300
    ios_version VARCHAR(50),   -- 16.12.03, 20.3.1
    serial_number VARCHAR(100),
    device_role VARCHAR(50),   -- core, distribution, access
    site VARCHAR(100),         -- lab, dc1, branch
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    last_updated TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    is_active BOOLEAN DEFAULT TRUE
);

CREATE INDEX idx_devices_hostname ON devices(hostname);
CREATE INDEX idx_devices_vendor ON devices(vendor);
CREATE INDEX idx_devices_role ON devices(device_role);
""")

conn.close()
```

### 2️⃣ 导入现有设备数据 (10分钟)

```python
# 从Nornir Inventory导入
from pathlib import Path
from nornir import InitNornir
import json

nr = InitNornir(config_file=".olav/config/nornir/config.yaml")

devices_data = []
for host_name, host_obj in nr.inventory.hosts.items():
    devices_data.append({
        'hostname': host_name,
        'ip_address': host_obj.hostname,
        'device_type': 'cisco_ios',  # 根据实际情况调整
        'vendor': 'Cisco',
        'device_role': 'core' if host_name.startswith('R') else 'access',
        'site': 'lab',
    })

# 插入数据库
conn = duckdb.connect(".olav/cache/semantic_cache.db")
for device in devices_data:
    conn.execute("""
        INSERT OR REPLACE INTO devices 
        (hostname, ip_address, device_type, vendor, device_role, site)
        VALUES (?, ?, ?, ?, ?, ?)
    """, [
        device['hostname'],
        device['ip_address'],
        device['device_type'],
        device['vendor'],
        device['device_role'],
        device['site'],
    ])

conn.close()
print(f"✅ 导入 {len(devices_data)} 个设备")
```

### 3️⃣ 更新LLM系统提示 (5分钟)

在 `src/olav/agents/orchestrator.py` 中更新系统提示:

```python
system_prompt = f"""
...现有提示...

**Available Database Tables**:

1. **devices** (Device Catalog)
   Columns: hostname, ip_address, vendor, model, ios_version, device_role, site
   Description: Device inventory with basic information
   Example: SELECT hostname FROM devices WHERE vendor='Cisco' AND device_role='core'

2. **v_lldp** (LLDP Neighbors)
   Columns: device, neighbor, local_interface, remote_interface
   
3. **v_bgp_neighbors** (BGP State)
   Columns: device, neighbor, state, asn
   
4. **v_ospf_neighbors** (OSPF State)  
   Columns: device, neighbor, state, router_id

**Important**: Always check 'devices' table FIRST for device information!
NEVER try to query a table named just "devices" with complex WHERE clauses without verifying it exists.
"""
```
