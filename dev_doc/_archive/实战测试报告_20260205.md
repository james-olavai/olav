## 测试场景概述

### 场景1: 接口IP地址变更导致邻居关系异常诊断

**目标**: 测试OLAV系统对网络配置变更引起的协议故障的诊断能力

**测试步骤**:

1. **修改R3接口配置**
   ```bash
   # 原配置
   interface ethernet0/0
     ip address 10.1.13.3 255.255.255.0
   
   # 修改为
   interface ethernet0/0
     ip address 10.1.13.3 255.255.255.252  # /24 → /30
   ```

2. **等待5秒**让OSPF/BGP协议感知变化

3. **查询OLAV诊断**
   ```
   查询: "R3的接口ethernet0/0的IP地址从10.1.13.3/24改成了10.1.13.3/30，
          R1和R3的OSPF邻居为什么会受影响？请分析根本原因并给出解决方案。"
   ```

4. **恢复配置**
   ```bash
   interface ethernet0/0
     ip address 10.1.13.3 255.255.255.0
   ```

**预期OLAV诊断结果**:

OLAV Expert Agent应该能够：

1. ✅ **识别问题根因**: 子网掩码从/24改为/30导致：
   - R3的网段从`10.1.13.0/24`变为`10.1.13.0/30`（只包含4个IP: .0, .1, .2, .3）
   - R1的IP地址`10.1.13.1`仍在原/24网段，但可能不在新的/30网段
   - OSPF邻居关系依赖于相同子网，掩码不匹配会导致邻居down

2. ✅ **分析影响范围**:
   - OSPF: 邻居关系down（因为子网不匹配或Dead Timer超时）
   - BGP: 可能受影响（如果BGP邻居建立在受影响的接口上）
   - 路由: OSPF路由丢失，影响网络可达性

3. ✅ **提供解决方案**:
   - **方案1**: 恢复原有掩码`255.255.255.0`（推荐）
   - **方案2**: 同时修改R1的掩码为/30，并确保两端IP在同一/30网段
   - **方案3**: 使用点对点链路配置（`ip ospf network point-to-point`）

4. ✅ **使用Expert工具**:
   - `analyze_topology()` - 分析R3的拓扑连接
   - `get_device_peers()` - 获取R3的OSPF邻居
   - `query_network()` - 查询OSPF邻居状态
   - `compare_device_configs()` - 对比R1和R3的接口配置
   - `generate_diagnosis_report()` - 生成专业诊断报告

### 场景2: VLAN互通配置需求分析

**目标**: 测试OLAV对网络配置需求的理解和方案设计能力

**测试查询**:
```
"现在SW1加入了VLAN10，SW2加入了VLAN20。
 如果要让两个交换机下对应VLAN的主机互通，需要做什么配置？
 请提供具体的配置命令和步骤。"
```

**预期OLAV配置建议**:

OLAV应该能够：

1. ✅ **理解需求**: 
   - SW1的VLAN10 ↔ SW2的VLAN20 互通
   - 不同VLAN需要三层路由

2. ✅ **提供配置方案**:

   **方案1: 使用路由器做三层路由**
   ```bash
   # R1配置（假设R1是三层设备）
   interface vlan 10
     ip address 192.168.10.1 255.255.255.0
   interface vlan 20
     ip address 192.168.20.1 255.255.255.0
   
   # SW1配置
   vlan 10
   interface vlanX
     switchport mode access
     switchport access vlan 10
   
   # SW2配置
   vlan 20
   interface vlanY
     switchport mode access
     switchport access vlan 20
   ```

   **方案2: 使用三层交换机做SVI**
   ```bash
   # 在其中一台支持三层的交换机上
   ip routing
   interface vlan 10
     ip address 192.168.10.1 255.255.255.0
   interface vlan 20
     ip address 192.168.20.1 255.255.255.0
   ```

   **方案3: VLAN Trunk + 路由器单臂路由**
   ```bash
   # Router配置
   interface g0/0.10
     encapsulation dot1Q 10
     ip address 192.168.10.1 255.255.255.0
   interface g0/0.20
     encapsulation dot1Q 20
     ip address 192.168.20.1 255.255.255.0
   
   # SW1/SW2配置
   interface trunk-to-router
     switchport mode trunk
     switchport trunk allowed vlan 10,20
   ```

3. ✅ **配置步骤**:
   1. 确认网络拓扑和三层设备位置
   2. 在三层设备上创建VLAN SVI并配置IP
   3. 配置交换机的VLAN和Trunk
   4. 验证路由表和连通性
   5. 配置ACL（如需要访问控制）

4. ✅ **验证命令**:
   ```bash
   show ip route
   show vlan brief
   show interface trunk
   ping 192.168.20.x source 192.168.10.y
   ```
