## Query

### POST /query
> Query data

**Parameters:**
- `org` (string) — Specifies the name of the organization executing the query. Takes either the ID or Name. If both `orgID` and `org` are specified, `org` takes precedence.
- `orgID` (string) — Specifies the ID of the organization executing the query. If both `orgID` and `org` are specified, `org` takes precedence.

### POST /query/analyze
> Analyze a Flux query

### POST /query/ast
> Generate an Abstract Syntax Tree (AST) from a query

### GET /query/suggestions
> Retrieve query suggestions

### GET /query/suggestions/{name}
> Retrieve query suggestions for a branching suggestion
