# 40. CI Testing Strategy — Fresh Venv Validation

**Date:** 2026-04-13
**Version:** v0.18.0
**Status:** Proposal
**Author:** OLAV Team

---

## 背景

v0.15.0→v0.17.0 的 demo runsheet 测试中发现 20+ bug，**全部被开发环境的隐含状态掩盖**。

根因分类：

| 掩盖类型 | 数量 | 例子 |
|---|:---:|---|
| 累积数据（旧 DB/表/模型） | 5 | topology_links 不存在、devices 表为空、LanceDB 维度不一致 |
| 手动干预（--no-deps、chmod） | 4 | deepagents-cli 手动装、run.py 权限 |
| 缓存状态（HF 模型、embedding） | 3 | 模型未下载、shard 输出噪音 |
| editable install 绕过打包 | 2 | wheel 缺文件、skill install 不覆盖 |
| 长期进程（不重启） | 2 | memory capture 未完成、syslog 端口占用 |
| 单一环境（localhost、IOS only） | 4 | secure cookie、Junos 命令、phantom view |

**核心教训：`pip install -e .` 和 `pip install dist/*.whl` 走完全不同的代码路径。开发环境永远不会发现打包遗漏、冷启动问题、依赖冲突。**

## 三层测试架构

### Tier 0：打包验证（每次 commit，零 LLM 成本）

**目标：** 验证 wheel 能在全新 venv 中安装、初始化、加载 skill。

**不需要：** LLM API key、网络设备、SSH 连接。

**环境要求：** Python 3.11+、`uv`、`olav-netops` 仓库路径。

**测试项：**

| # | 检查 | 验证方式 | 失败标准 |
|---|---|---|---|
| 1 | Wheel 内容完整 | `unzip -l *.whl \| grep AGENT.md` | 缺少非 .py 文件 |
| 2 | 零冲突安装 | `pip install *.whl && pip check` | 依赖冲突 |
| 3 | `olav init` 无错误 | grep `✓` 和 `⚠`，不允许 traceback | 任何未捕获异常 |
| 4 | 无噪音输出 | 不含 "layers were not sharded"、HF Hub warning | stderr 泄漏 |
| 5 | `skill install` 2 workspace | grep "2 workspaces" | 多 workspace 安装失败 |
| 6 | `olav list` 3 agents | grep core, ops, audit | agent 未注册 |
| 7 | `netops_init --dry-run` | grep "inventory validated" | 环境检查失败 |
| 8 | DB schema 完整 | 查 5 张 netops 表 | 表未创建 |
| 9 | Web API `/health` | curl 返回 200 | 服务启动失败 |
| 10 | Web API `/agents` | JSON 数组 ≥3 个 agent | 动态 agent 列表失败 |

**脚本：** `tests/ci/tier0_packaging.sh`

**缓存隔离：**
- 每次运行在 `/tmp/olav-ci-{timestamp}` 下创建全新目录
- `HOME` 环境变量指向临时目录，避免 `~/.olav/token` 等文件干扰
- 运行前 `unset HF_TOKEN OPENAI_API_KEY ANTHROPIC_API_KEY` 确保无隐含 API key
- embedding 模型首次下载是 init 的一部分，不应该跳过

```bash
#!/bin/bash
# tests/ci/tier0_packaging.sh
set -euo pipefail

TIMESTAMP=$(date +%Y%m%d_%H%M%S)
TEST_DIR="/tmp/olav-ci-${TIMESTAMP}"
NETOPS_DIR="${OLAV_NETOPS_DIR:-/home/yhvh/Olav/olav-netops}"

# ── 隔离环境 ──────────────────────────────────────────────────
export HOME="${TEST_DIR}/fakehome"
mkdir -p "$HOME"
unset HF_TOKEN OPENAI_API_KEY ANTHROPIC_API_KEY OLAV_API_KEY 2>/dev/null || true

echo "=== Tier 0: Packaging Validation ==="
echo "  Test dir: ${TEST_DIR}"
echo "  Wheel:    $(ls dist/*.whl 2>/dev/null | tail -1)"

# ── 1. Wheel 内容 ─────────────────────────────────────────────
WHEEL=$(ls dist/*.whl | tail -1)
echo -n "[1/10] Wheel content... "
unzip -l "$WHEEL" | grep -q "AGENT.md" || { echo "FAIL: missing AGENT.md"; exit 1; }
unzip -l "$WHEEL" | grep -q "system.md" || { echo "FAIL: missing system.md"; exit 1; }
unzip -l "$WHEEL" | grep -q "execute_sql.py" || { echo "FAIL: missing execute_sql.py"; exit 1; }
echo "OK"

# ── 2. 全新 venv 安装 ─────────────────────────────────────────
echo -n "[2/10] Fresh venv install... "
mkdir -p "${TEST_DIR}"
python3 -m venv "${TEST_DIR}/.venv"
PIP="${TEST_DIR}/.venv/bin/pip"
OLAV="${TEST_DIR}/.venv/bin/olav"
$PIP install -q "$WHEEL" 2>&1 | tail -1
$PIP check > /dev/null 2>&1 || { echo "FAIL: dependency conflict"; exit 1; }
echo "OK"

# ── 3. olav init ──────────────────────────────────────────────
echo -n "[3/10] olav init... "
cd "${TEST_DIR}"
INIT_LOG=$($OLAV init 2>&1)
echo "$INIT_LOG" | grep -q "✓ domain.duckdb" || { echo "FAIL"; echo "$INIT_LOG"; exit 1; }
echo "$INIT_LOG" | grep -q "✓ core workspace" || { echo "FAIL"; echo "$INIT_LOG"; exit 1; }
echo "$INIT_LOG" | grep -qi "traceback" && { echo "FAIL: traceback in init"; echo "$INIT_LOG"; exit 1; }
echo "OK"

# ── 4. 无噪音输出 ─────────────────────────────────────────────
echo -n "[4/10] Clean output... "
echo "$INIT_LOG" | grep -q "layers were not sharded" && { echo "FAIL: safetensors noise"; exit 1; }
echo "OK"

# ── 5. Skill install ─────────────────────────────────────────
echo -n "[5/10] Skill install... "
SKILL_LOG=$($OLAV skill install "$NETOPS_DIR" 2>&1)
echo "$SKILL_LOG" | grep -q "2 workspaces" || { echo "FAIL"; echo "$SKILL_LOG"; exit 1; }
echo "OK"

# ── 6. Agent list ─────────────────────────────────────────────
echo -n "[6/10] Agent list... "
LIST_LOG=$($OLAV list 2>&1)
for agent in core ops audit; do
  echo "$LIST_LOG" | grep -q "$agent" || { echo "FAIL: missing $agent"; exit 1; }
done
echo "OK (3 agents)"

# ── 7. Dry-run ────────────────────────────────────────────────
echo -n "[7/10] netops_init --dry-run... "
# 需要 hosts.yaml
cp "${NETOPS_DIR}/.olav/workspace/ops/probe/config/nornir/hosts.yaml.example" \
   .olav/workspace/ops/probe/config/nornir/hosts.yaml 2>/dev/null || true
DRY_LOG=$($OLAV --agent ops "/netops_init --dry-run" 2>&1)
echo "$DRY_LOG" | grep -q "inventory validated" || echo "$DRY_LOG" | grep -q "Dry-run complete" || { echo "FAIL"; echo "$DRY_LOG"; exit 1; }
echo "OK"

# ── 8. DB schema ──────────────────────────────────────────────
echo -n "[8/10] DB schema... "
${TEST_DIR}/.venv/bin/python3 -c "
import duckdb, sys
con = duckdb.connect('.olav/databases/main.duckdb', read_only=True)
tables = [r[0] for r in con.execute(
    \"SELECT table_name FROM information_schema.tables WHERE table_schema='netops'\"
).fetchall()]
expected = ['parsed_outputs','raw_output_store','topology_links','devices','oc_outputs']
missing = [t for t in expected if t not in tables]
if missing:
    print(f'FAIL: missing tables: {missing}', file=sys.stderr)
    sys.exit(1)
print('OK')
" || exit 1

# ── 9-10. Web API ─────────────────────────────────────────────
echo -n "[9/10] Web API health... "
$OLAV service start --all > /dev/null 2>&1
sleep 2
curl -sf http://localhost:2280/health | grep -q "healthy" || { echo "FAIL"; exit 1; }
echo "OK"

echo -n "[10/10] Web API /agents... "
AGENT_COUNT=$(curl -sf http://localhost:2280/agents | python3 -c "import sys,json; print(len(json.load(sys.stdin)))")
[ "$AGENT_COUNT" -ge 5 ] || { echo "FAIL: only $AGENT_COUNT agents"; exit 1; }
echo "OK ($AGENT_COUNT agents)"

# ── 清理 ──────────────────────────────────────────────────────
pkill -f "uvicorn.*olav.*2280" 2>/dev/null || true
pkill -f "syslog_receiver" 2>/dev/null || true

echo ""
echo "✅ Tier 0 PASSED — all 10 checks in ${TEST_DIR}"
echo "   Clean up: rm -rf ${TEST_DIR}"
```

### Tier 1：LLM E2E（每日/PR，~$0.05 成本）

**目标：** 验证 LLM 查询能执行并返回合理结果。

**需要：** LLM API key（OpenRouter grok-4.1-fast ~$0.01/query）。

**不需要：** 真实网络设备（用 seed 数据）。

**测试项：**

| # | 查询 | 验证 | 缓存行为 |
|---|---|---|---|
| 1 | "列出所有设备" | 输出包含 ≥1 设备名、有 tool call | 首次：miss，cache put |
| 2 | "所有BGP邻居状态" | 输出非空、无 traceback | 首次：miss |
| 3 | "列出所有设备"（重复） | **无 tool call**（cache hit） | 命中 |
| 4 | "有多少台设备"（变体） | 输出包含数字 | 可能 miss（语义不同） |
| 5 | Memory 验证 | `memory` 表 >0 行 | AutoCapture 工作 |

**缓存隔离策略：**

```bash
# 每次 Tier 1 测试前清空 memory + cache
rm -rf "${TEST_DIR}/.olav/databases/memory.lance"
rm -rf "${TEST_DIR}/.olav/databases/memory.lancedb"
```

**注意：** 进程启动开销 (~10s) 无法避免（Python import + embedding 模型加载）。LLM 调用 (~3-5s) 才是 cache 节省的部分。验证 cache 命中时应检查**是否有 tool call**，而非纯时间差。

```bash
#!/bin/bash
# tests/ci/tier1_llm_e2e.sh
set -euo pipefail

TEST_DIR="${1:-/tmp/olav-ci-latest}"
OLAV="${TEST_DIR}/.venv/bin/olav"
cd "${TEST_DIR}"

# ── 前置：配置 LLM + seed 测试数据 ────────────────────────────
${TEST_DIR}/.venv/bin/python3 -c "
import json
a = json.load(open('.olav/config/api.json'))
a['shared']['api_key'] = '${OLAV_API_KEY}'
a['llm'] = {'model':'x-ai/grok-4.1-fast','base_url':'https://openrouter.ai/api/v1'}
a['embedding'] = {'mode':'local'}
a['auth'] = {'mode':'none'}
json.dump(a, open('.olav/config/api.json','w'), indent=2, ensure_ascii=False)
"

# Seed 测试数据（模拟 netops_init 输出，不需要真实设备）
${TEST_DIR}/.venv/bin/python3 tests/fixtures/seed_test_data.py

# 清空 memory + cache（隔离）
rm -rf .olav/databases/memory.lance .olav/databases/memory.lancedb

echo "=== Tier 1: LLM E2E ==="

# ── Q1: 首次查询 ─────────────────────────────────────────────
echo -n "[1/5] 列出所有设备 (cold)... "
Q1=$($OLAV "列出所有设备" 2>&1)
echo "$Q1" | grep -qi "traceback" && { echo "FAIL: traceback"; exit 1; }
echo "$Q1" | grep -q "🔧" || { echo "FAIL: no tool call"; exit 1; }
[ ${#Q1} -gt 50 ] || { echo "FAIL: output too short"; exit 1; }
echo "OK"

# ── Q2: BGP 查询 ─────────────────────────────────────────────
echo -n "[2/5] BGP邻居状态... "
Q2=$($OLAV "所有BGP邻居状态" 2>&1)
echo "$Q2" | grep -qi "traceback" && { echo "FAIL"; exit 1; }
[ ${#Q2} -gt 50 ] || { echo "FAIL: output too short"; exit 1; }
echo "OK"

# ── Q3: Cache hit 验证 ────────────────────────────────────────
echo -n "[3/5] Cache hit (repeat Q1)... "
Q3=$($OLAV "列出所有设备" 2>&1)
if echo "$Q3" | grep -q "🔧"; then
  echo "WARN: cache miss (tool call present)"
else
  echo "OK (no tool call = cache hit)"
fi

# ── Q4: 变体查询 ─────────────────────────────────────────────
echo -n "[4/5] 变体查询 '有多少台设备'... "
Q4=$($OLAV "有多少台设备" 2>&1)
echo "$Q4" | grep -qi "traceback" && { echo "FAIL"; exit 1; }
[ ${#Q4} -gt 10 ] || { echo "FAIL"; exit 1; }
echo "OK"

# ── Q5: Memory 验证 ──────────────────────────────────────────
echo -n "[5/5] Memory capture... "
MEM=$(${TEST_DIR}/.venv/bin/python3 -c "
import lancedb; db=lancedb.connect('.olav/databases/memory.lance')
t=db.open_table('memory'); print(t.count_rows())
" 2>&1 | grep -v Deprec | tail -1)
[ "$MEM" -gt 0 ] || { echo "FAIL: 0 memories"; exit 1; }
echo "OK ($MEM memories)"

echo ""
echo "✅ Tier 1 PASSED"
```

### Tier 2：全集成（发版前，需要设备 + agent 辅助）

**目标：** 完整 Demo Runsheet CH1-CH4。

**需要：** LLM API key、SSH 可达的网络设备、ContainerLab（可选）。

**不能完全自动化的原因：**

| 测试项 | 为什么需要人/agent 判断 |
|---|---|
| SSH 采集质量 | 输出因设备状态而异 |
| LLM 回答准确性 | "BGP 全部 Established" 是否正确解读 |
| 拓扑图合理性 | Mermaid 图是否反映真实拓扑 |
| 故障场景 | 设备 down、API key 过期等边界情况 |

**半自动化方案：** 脚本跑完所有步骤，输出 report，由 agent 或人工审查。

## 缓存隔离设计

### 问题

Cache 和 Memory 会在测试间泄漏状态：
- Cache hit 让第二次查询跳过 LLM → 无法验证 LLM 行为
- Memory 积累的 facts 影响后续查询的 agent 行为
- LanceDB 表的维度不匹配导致静默错误

### 策略

| 场景 | 隔离方式 |
|---|---|
| Tier 0（不用 LLM） | 每次全新目录 + `HOME` 重定向 |
| Tier 1 cache miss 测试 | 删除 `memory.lance` + `memory.lancedb` |
| Tier 1 cache hit 测试 | 保留 cache，验证无 tool call |
| Tier 2 全集成 | 全新目录，从 `olav init` 开始 |
| 开发环境调试 | **永远不作为验证手段** |

### 数据变更自动失效（v0.17.0+）

Cache 假阳性问题已通过 `IngestManager.bulk_load()` 后自动调用 `SemanticCache.invalidate_all()` 解决。

失效触发链：
```
netops_init / take_snapshot → IngestManager.bulk_load() → cache.invalidate_all() → drop query_cache
```

附加保护：
- TTL 24h（可通过 `api.json` 的 `memory.cache_ttl_hours` 配置）
- 相似度阈值 0.02（cosine distance，即 98% 相似才命中）
- 容量上限 500 条（LRU 淘汰）

### 环境变量隔离

```bash
# 避免开发环境残留影响测试

unset HF_TOKEN OPENAI_API_KEY ANTHROPIC_API_KEY
```

## 测试数据 Seed

Tier 1 不需要真实设备。用 Python 脚本直接向 DuckDB 注入测试数据：

```python
# tests/fixtures/seed_test_data.py
"""Seed netops tables with synthetic data for Tier 1 LLM E2E tests."""
import duckdb
import json
from pathlib import Path

DB_PATH = Path(".olav/databases/main.duckdb")

def seed():
    with duckdb.connect(str(DB_PATH)) as con:
        con.execute("CREATE SCHEMA IF NOT EXISTS netops")
        
        # Ensure tables exist (via entry-points or fallback DDL)
        try:
            from olav_netops.core.tables import _register_all
            from olav.platform.ingest_base import TableRegistry
            _register_all()
            TableRegistry.ensure_all_schemas(con)
        except ImportError:
            pass  # tables should exist from skill install
        
        # Seed devices
        devices = [
            ("R1", "192.168.100.101", "juniper_junos", "Juniper", "vsrx", "18.4R3-S3"),
            ("R2", "2.2.2.2", "cisco_ios", "Cisco", "ISRV", "17.1.1"),
            ("R3", "3.3.3.3", "cisco_ios", "Cisco", None, "17.15.1"),
            ("SW1", "192.168.100.105", "cisco_ios", "Cisco", None, "17.15.1"),
        ]
        for hostname, ip, plat, vendor, model, ver in devices:
            con.execute("""
                INSERT INTO netops.devices (hostname, ip_address, platform, vendor, model, os_version, last_seen)
                VALUES (?, ?, ?, ?, ?, ?, NOW())
                ON CONFLICT (hostname) DO NOTHING
            """, [hostname, ip, plat, vendor, model, ver])
        
        # Seed parsed_outputs (BGP summary for R2)
        bgp_data = json.dumps([
            {"BGP_NEIGH": "3.3.3.3", "NEIGH_AS": "65000", "STATE_PFXRCD": "0", "UP_DOWN": "2w3d"},
        ])
        con.execute("""
            INSERT INTO netops.parsed_outputs (device_name, command, parsed_data, snapshot_id)
            VALUES ('R2', 'show ip bgp summary', ?::JSON, 'snap_test')
            ON CONFLICT (device_name, command, snapshot_id) DO NOTHING
        """, [bgp_data])
        
        # Seed topology
        con.execute("""
            INSERT INTO netops.topology_links 
                (link_id, source_device, source_interface, destination_device, destination_interface,
                 discovery_protocol, link_type, link_status, first_seen, last_seen, snapshot_id)
            VALUES ('test-1', 'R1', 'ge-0/0/0', 'R2', 'Gi1', 'LLDP', 'L2', 'up', NOW(), NOW(), 'snap_test')
            ON CONFLICT (link_id) DO NOTHING
        """)
    
    print(f"Seeded: {len(devices)} devices, 1 BGP record, 1 topology link")

if __name__ == "__main__":
    seed()
```

## 附录：开发环境 vs 测试环境差异表

| 方面 | 开发环境 | CI 测试环境 |
|---|---|---|
| 安装方式 | `pip install -e .` | `pip install dist/*.whl` |
| LanceDB | 已有表、已有数据 | 空 |
| DuckDB | 历史 migration 数据 | 从 init/skill install 建表 |
| HF 模型 | 已缓存 | init 时首次下载 |
| deepagents-cli | 手动 `--no-deps` | 正常 pip 解析 |
| 进程状态 | 长期运行、有热缓存 | 冷启动 |
| 网络访问 | localhost | 可能远程 |
| HOME 目录 | 有 `~/.olav/token` 等 | 空 |
| 环境变量 | 可能有 `HF_TOKEN` 等 | 显式 unset |
