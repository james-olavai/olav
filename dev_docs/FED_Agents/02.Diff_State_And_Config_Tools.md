# 🔄 Diff Expert Tools: diff_sql_state & diff_raw_configs

This document outlines the design for the core state comparison tools within the `ops` agent's Diff Subagent. These tools allow the LLM to understand how the network has changed between two points in time (snapshots).

## 1. `diff_sql_state` (Universal State Comparison)

### Purpose
To perform a structured, noisy-free comparison of any standard operational table between two `snapshot_id`s, returning only the Delta (what was added and what was removed).

### Design Inspiration
Inspired by Cisco pyATS `Learn` parsing and state diffing, but executed natively within DuckDB using SQL set operations (`EXCEPT` / `MINUS`).

### Implementation Strategy
The tool takes three arguments:
1. `table_name`: The target operational table (e.g., `ospf_neighbors`, `interfaces`, `devices`, `bgp_neighbors`).
2. `snapshot_id_1`: The reference or "before" state (e.g., $T1$).
3. `snapshot_id_2`: The current or "after" state (e.g., $T2$).

#### Core Logic
Instead of the LLM fetching 1000 rows from $T1$ and 1000 rows from $T2$ and trying to compare them (which breaks context windows), this Python tool executes the comparison in the database:

**Missing in T2 (What broke/disappeared):**
```sql
SELECT * FROM table_name WHERE snapshot_id = 'T1'
EXCEPT
SELECT * FROM table_name WHERE snapshot_id = 'T2'
```

**New in T2 (What was added):**
```sql
SELECT * FROM table_name WHERE snapshot_id = 'T2'
EXCEPT
SELECT * FROM table_name WHERE snapshot_id = 'T1'
```

### Output Format
Returns a concise JSON object containing only the differences:
```json
{
  "table": "ospf_neighbors",
  "missing_in_t2": [
    {"device_name": "R1", "neighbor_ip": "10.1.1.2", "state": "FULL"}
  ],
  "new_in_t2": [
    {"device_name": "R1", "neighbor_ip": "10.1.1.2", "state": "INIT"}
  ]
}
```

## 2. `diff_raw_configs` (Configuration Comparison)

### Purpose
To perform a standard `diff` (like `git diff` or GNU `diff`) between the raw configuration files collected during two different snapshots.

### Implementation Strategy
This is an evolution of the existing `diff_configs` tool, updated to strictly use the new `snapshot_id` directory structure.

1. **Locate Files**: Uses the provided `snapshot_id_1` and `snapshot_id_2` to locate the corresponding raw text output files in `exports/snapshots/<snapshot_date>/raw/`.
2. **Execute Diff**: Uses Python's `difflib.unified_diff` to compare the two text files.
3. **Filter Noise**: Optionally filters out lines like timestamps or `ntp clock` that constantly change to avoid distracting the LLM.

### Output Format
Returns standard unified diff format strings for the requested devices:
```diff
--- R1_T1.txt
+++ R1_T2.txt
@@ -10,3 +10,2 @@
  router ospf 1
- network 10.0.0.0 0.255.255.255 area 0
  network 192.168.1.0 0.0.0.255 area 0
```
