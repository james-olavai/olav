## 2. 文档站（Phase 1）

### 2.1 技术选型：MkDocs + Material Theme

**理由：**
- OLAV 是 Python 项目，MkDocs 是 Python 原生，不引入 Node.js 构建链
- Material theme 是技术文档领域事实标准
- 开箱即用的功能：全文搜索、中英双语（i18n）、暗色主题、Mermaid 图渲染、代码高亮
- `mkdocs-awesome-pages-plugin` 直接映射现有 `docs/` 目录，零改动

**核心依赖：**
```toml
# pyproject.toml [dependency-groups.docs]
mkdocs = ">=1.6"
mkdocs-material = ">=9.5"
mkdocs-awesome-pages-plugin = ">=2.9"
mkdocs-static-i18n = ">=1.2"   # 中英切换
```

### 2.2 目录映射

现有 `docs/` 结构直接复用：

### 2.3 mkdocs.yml 核心配置

```yaml
site_name: OLAV Platform
site_url: https://docs.olavplatform.com
docs_dir: docs
theme:
  name: material
  language: zh
  palette:
    - scheme: default
      toggle:
        icon: material/brightness-7
        name: 切换暗色主题
    - scheme: slate
      toggle:
        icon: material/brightness-4
        name: 切换亮色主题
  features:
    - navigation.tabs          # 顶部导航
    - navigation.sections
    - search.highlight
    - content.code.copy        # 代码块复制按钮

plugins:
  - search:
      lang: [zh, en]
  - awesome-pages              # 自动读取目录结构

markdown_extensions:
  - pymdownx.superfences:
      custom_fences:
        - name: mermaid        # Mermaid 图支持
          class: mermaid
          format: !!python/name:pymdownx.superfences.fence_code_format
  - admonition                 # !!! note / warning / tip
  - pymdownx.highlight
  - pymdownx.tabbed
  - toc:
      permalink: true
```

### 2.4 Cloudflare Pages 部署配置

```
Repository:          github/Olav（现有仓库）
Production branch:   main
Build command:       pip install mkdocs mkdocs-material mkdocs-awesome-pages-plugin && mkdocs build
Output directory:    site
Root directory:      /（项目根）
```

**DNS 配置（在 Cloudflare Dashboard）：**
```
CNAME  docs  →  olav-docs.pages.dev   （自动 SSL）
```

### 2.5 GitHub Actions（可选，替代 Cloudflare 内置构建）

```yaml
# .github/workflows/docs.yml
name: Deploy Docs
on:
  push:
    branches: [main]
    paths: [docs/**, mkdocs.yml]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: "3.12" }
      - run: pip install mkdocs mkdocs-material mkdocs-awesome-pages-plugin
      - run: mkdocs gh-deploy --force
        # 或: mkdocs build && wrangler pages deploy site
```

> 推荐直接用 Cloudflare Pages 内置 CI，无需额外 workflow，push 即触发。

## 3. 商业主站（Phase 2）

> 文档站上线后再启动

### 3.1 技术选型：Astro + Tailwind CSS

**理由：**
- 输出纯静态 HTML，Cloudflare Pages 直接托管，无服务器成本
- Tailwind CSS 快速构建 Landing Page
- 原生支持 MDX（博客 / 更新日志直接写 Markdown）
- 构建速度远快于 Next.js

**页面结构（规划）：**
```
/              Hero + 核心价值主张 + CTA
/features      功能展示（平台 + NetOps 能力）
/pricing       定价（开源 / Enterprise）
/blog          技术博客（MDX）
/changelog     CHANGELOG.md 自动渲染
               → docs.olavplatform.com  （外链）
```

**单独仓库：**`github/<org>/olav-website`，与主仓库解耦。

### 3.2 Cloudflare Pages 部署配置

```
Repository:         github/<org>/olav-website
Build command:      npm run build
Output directory:   dist
```

### 3.3 未来可扩展的 Cloudflare 产品

| 需求 | 产品 | 免费额度 |
|------|------|----------|
| 联系表单 / 邮件收集 | Workers + D1 | 10万请求/天 |
| 文档站登录鉴权（Enterprise） | Cloudflare Access | ≤50人免费 |
| 站点分析（无 Cookie） | Web Analytics | 免费 |
| 图片优化 | Images | $5/月起 |

## 4. 执行路径

```
Phase 1（文档站）
  Step 1: 在 pyproject.toml 添加 [docs] 依赖组
  Step 2: 创建 mkdocs.yml 配置文件
  Step 3: 补全缺失的文档页面（creator-agent / skill-guide）
  Step 4: Cloudflare Pages 连接仓库，配置构建命令
  Step 5: 绑定自定义域名 docs.olavplatform.com

Phase 2（主站）
  Step 1: 新建 olav-website 仓库，Astro 初始化
  Step 2: 设计 Landing Page（Hero + Features + Pricing）
  Step 3: Cloudflare Pages 部署，绑定根域名
```

---

## 5. 关键约束

- **不在主仓库（Olav）存放主站代码**：主仓库只负责 docs/ → 文档站
- **中文文档与英文文档保持同步**：新功能文档同时写中英两版
- **文档站 URL 固定为 `docs.*`**：便于从主站、README、CLI help 统一外链
