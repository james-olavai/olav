# 100. OLAV CI Test Plan — v0.18.0

**Date:** 2026-04-14
**Owner:** Testing Team
**Scope:** All platform core + netops extension functionality
**Coverage Target:** 100% of claim registry + critical paths

**Agent Architecture (v0.18.0+):** 3 top-level agents only

| Agent | Package | Role |
|---|---|---|
| `core` | olav (wheel) | Platform operations, quick queries, system management |
| `ops` | olav-netops | Network operations: SSH, analysis, diff, lab, devops, infra |
| `audit` | olav-netops | Learning, compliance: designer, auditor, learner |

---

## Architecture

```
┌─────────────────────────────────────────────────────────┐
│ Tier 0: Packaging & Init (every commit, 0 cost)         │
│  Phase A: olav core only (17 checks)                    │
│  Phase B: olav + netops (11 checks)                     │
├─────────────────────────────────────────────────────────┤
│ Tier 1: Functional (daily, ~$0.10 LLM cost)             │
│  50 checks — tools, KB, auth, API, query, cache         │
├─────────────────────────────────────────────────────────┤
│ Tier 2: Integration (pre-release, ~$1.00 + devices)     │
│  25 checks — SSH, lab, audit, multi-user, runsheet      │
└─────────────────────────────────────────────────────────┘
```

**总计：~100 项测试**

## 环境准备

### 通用前置

```bash
# 1. Build wheel
cd /path/to/olav
uv build

# 2. Set variables
export OLAV_WHEEL=$(ls dist/*.whl | tail -1)
export OLAV_NETOPS_DIR=/path/to/olav-netops
export OLAV_API_KEY="sk-or-v1-..."  # Tier 1+ only
export OLAV_TEST_DEVICE_IP="192.168.100.101"  # Tier 2 only
```

### 隔离原则

| 原则 | 实现 |
|---|---|
| 全新 venv | `/tmp/olav-ci-{timestamp}/.venv` |
| 隔离 HOME | `export HOME=/tmp/olav-ci-xxx/fakehome` |
| 无残留 API key | `unset HF_TOKEN OPENAI_API_KEY ANTHROPIC_API_KEY` |
| 无残留进程 | 测试前 `pkill -f "uvicorn\|syslog_receiver\|olav.*daemon"` |
| 无 cache 干扰 | 每个 Tier 开始前清空 `memory.lance` |
| 数据隔离 | Tier 1 用 seed_test_data.py，不依赖真实设备 |

## 缺陷分类与处理

| 级别 | 定义 | 响应 |
|---|---|---|
| **P0 Blocker** | Tier 0 失败 | 立即修复，阻塞所有 merge |
| **P1 Critical** | Tier 1 核心查询/auth/KB 失败 | 24h 内修复，阻塞 release |
| **P2 Major** | Tier 1 非核心或 Tier 2 失败 | 下个 sprint 修复 |
| **P3 Minor** | Warning（safetensors 噪音等） | 排期修复 |
