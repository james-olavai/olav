### ISSUE-P0-WHEEL-MISSING-WORKSPACE-FILES

**状态**: Open
**发现日期**: 2026-04-12
**阻塞**: 发布

`olav-0.15.0-py3-none-any.whl` 只包含 `.py` 文件。`src/olav/data/workspace/core/` 的非 Python 文件（AGENT.md, SKILL.md, MANIFEST.yaml, prompts/*.md, references/*.md）**全部缺失**。

**后果：** `olav init` 部署的 core workspace 只有 `tools/` 目录，无 AGENT.md → `olav list` 不显示 core → `olav refresh` 找不到 agent → 路由失败。

**根因：** `pyproject.toml` 的 `[tool.hatch.build.targets.wheel]` include 有 `*.md` `*.yaml` pattern，但 hatchling 只打包 Python 包（有 `__init__.py` 的目录）。`prompts/` 和 `references/` 没有 `__init__.py` 所以被跳过。

**修复：**

```toml
[tool.hatch.build.targets.wheel]
packages = ["src/olav"]
# 显式 force-include 非 Python 目录
[tool.hatch.build.targets.wheel.force-include]
"src/olav/data/workspace/core/AGENT.md" = "olav/data/workspace/core/AGENT.md"
"src/olav/data/workspace/core/SKILL.md" = "olav/data/workspace/core/SKILL.md"
"src/olav/data/workspace/core/MANIFEST.yaml" = "olav/data/workspace/core/MANIFEST.yaml"
"src/olav/data/workspace/core/prompts" = "olav/data/workspace/core/prompts"
"src/olav/data/workspace/core/references" = "olav/data/workspace/core/references"
```

或更简单 — 在 `prompts/` 和 `references/` 中放空 `__init__.py` 让 hatchling 识别为包。

**验证：** 重新 build → `unzip -l dist/*.whl | grep -E "AGENT\.md|SKILL\.md|prompts|references"` 应有文件。
