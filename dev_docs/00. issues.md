### ISSUE-P2-DB-DIRTY-REBUILD-REQUIRED

**状态**: Open — blocked (CLAB offline)
**发现日期**: 2026-04-11
**影响测试**: 8 FAIL（gate tests）

多轮开发积累的 `main.duckdb` 存在不可修复的数据问题：
- SW1/SW2 Loopback0 IP 与 R4 相同（4.4.4.4）— 旧采集残留
- `topology_links` 含旧 self-loop 数据（新代码已过滤但旧行仍在）
- R2→R4 LLDP link 缺失（DB 重采后应出现）
- NL 测试返回脏数据（state=0 而非 "Idle"/"Established"）

#### 解决方案

```bash
# 1. 备份
cp .olav/databases/main.duckdb .olav/databases/main.duckdb.bak.20260411

# 2. 删库
rm .olav/databases/main.duckdb

# 3. 重采（自动建表 + IngestManager + topology ETL）
olav --agent ops "/netops_init"

# 4. 验证
uv run pytest tests/gates/ -q
```

需 CLAB 环境可用。重采后 8 个 gate FAIL 应消失。
