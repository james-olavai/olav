## 前瞻路线图（2026 Q2-Q3）

三个发布里程碑，顺序推进，前一个完成才启动下一个。

```
M1  OLAV Platform + 平台文档发布   ← 当前焦点
    发布渠道：PyPI（pip install olav）+ docs.olavai.com

M2  NetOps 发布                   ← M1 完成后启动
    发布渠道：GitHub 公开仓库（pip install olav-netops）

M3  Enterprise 功能完善            ← M2 完成后启动
    发布渠道：GitHub 私有仓库（客户授权访问）
```

**发布渠道决策摘要：**

| 包 | 仓库 | 可见性 | 安装方式 |
|----|------|--------|----------|
| `olav` | github/Olav（当前） | 公开 | `pip install olav` |
| `olav-netops` | github/olav-netops（待独立） | **公开** | `pip install olav-netops` |
| `olav-ent` | github/olav-ent（已存在骨架） | **私有** | `pip install git+https://github.com/<org>/olav-ent` |

**影响：**
- Repo 物理拆分（`olav-netops` 独立）是 M2 的**前置条件**，不是 Deferred
- `olav-ent` 私有仓库需要客户 GitHub 账号授权或 SSH key
- `docs/netops/` 随主文档站公开发布；Enterprise 文档单独维护（私有 wiki 或 Cloudflare Access 鉴权页）
- License 边界：`olav` + `olav-netops` 用开源 License；`olav-ent` 用商业 License
