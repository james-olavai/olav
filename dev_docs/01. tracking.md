## 3. 测试规范

**断言要求（继承 v0.13 规范）：**
- 必须调用真实 agent（subprocess）或真实工具（`.invoke()`）
- 验证输出内容（不仅 exit code）
- 走完整数据管道（不绕过 staging/IngestManager）
- 输出质量达到生产要求（数据量、格式、内容正确性）

**发现问题的流程：**
1. 测试失败 → 写入 `dev_docs/00. issues.md`
2. 分析根因 → 给出解决方案
3. 修复 → 验证 → 关闭 issue
