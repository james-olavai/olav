## 3. v0.14.0 Release Notes（草稿）

### 新功能
- **统一知识存储 (UKS)** — `olav kb` 命令组：import/export/sync/search/graph/status/backfill-tags
- **知识图谱** — LanceDB 向量空间 + tags 显式边 + vis.js 交互式 HTML
- **Obsidian 双向同步** — export → 编辑 → sync 回 LanceDB
- **多用户** — `olav init` 自动建 admin + token；`olav admin add-user` Linux 验证；session 隔离 + 跨界面恢复
- **Thread 归属** — API 403 校验，admin 可访问全部
- **Syslog 日志搜索** — `search_logs` core skill，DuckDB read_parquet
- **全局 Agent 注册表** — `olav refresh` 动态更新 PLATFORM.md + routing table
- **auth.mode 安全** — init 默认 token 模式；`auth.mode=none` 启动 WARNING

### 清理
- 删除 NETCONF/ncclient 死代码（~500 行）
- 删除 OC schema_engine/cache/mutation_service（~950 行）
- 删除 4 个死依赖（pygnmi/xmltodict/pyang/yangson）
- deepagents-cli 正式依赖（无需 --no-deps）
- 旧 KB 系统完全移除（kb_chunks → 统一 memory 表）

### 测试
- 1490 passed, 0 FAIL (unit + gate)
- LLM E2E: 15 passed + 14 xpassed + 7 skipped (infra-gated), 0 FAIL
- Claim registry: 119 条
- Issues: 161 条全关闭
