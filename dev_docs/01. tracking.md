### Phase 0: 环境准备

```bash
# 源代码根目录（用于复制配置）
OLAV_SRC=/home/yhvh/Olav

# 全新 venv
mkdir ~/olav-runsheet-test && cd ~/olav-runsheet-test
python3 -m venv .venv && source .venv/bin/activate

# 安装 OLAV
pip install olav==0.14.0
# 如果从 TestPyPI：
# pip install --index-url https://test.pypi.org/simple/ \
#             --extra-index-url https://pypi.org/simple/ olav==0.14.0

# SSH 采集依赖
pip install nornir nornir-netmiko
```

### Phase 1: olav init + 配置复制

```bash
# 1. 初始化（自动建用户 + token + auth.mode=token）
olav init
# 验证：
#   ✓ Admin user 创建
#   ✓ ~/.olav/token 存在
#   ✓ .olav/config/api.json auth.mode=token

# 2. 复制 API 配置（LLM key + 服务配置）
cp $OLAV_SRC/.olav/config/api.json .olav/config/api.json

# 3. 安装 NetOps skill（从本地源码）
olav skill install $OLAV_SRC/olav-netops/
# 验证：
#   ✓ ops workspace 部署
#   ✓ PLATFORM.md auto-refreshed

# 4. 复制 Nornir 设备清单
cp $OLAV_SRC/.olav/workspace/ops/probe/config/nornir/hosts.yaml \
   .olav/workspace/ops/probe/config/nornir/hosts.yaml
cp $OLAV_SRC/.olav/workspace/ops/probe/config/nornir/defaults.yaml \
   .olav/workspace/ops/probe/config/nornir/defaults.yaml

# 5. 复制服务配置（NetBox/InfluxDB/CLAB，如需 Ch5/7）
cp -r $OLAV_SRC/.olav/services/ .olav/services/ 2>/dev/null || true
cp -r $OLAV_SRC/.olav/workspace/ops-lab/config/ \
      .olav/workspace/ops-lab/config/ 2>/dev/null || true

# 6. 验证
olav list
# Expected: core, ops, quick, config, audit, devops, infra
olav version
# Expected: olav v0.14.0
```
