### GAP-04: response_extractor — 列表截断 + 信封解包

**Claim：** OLAV 自动截断过大的 API 响应，防止 LLM context 溢出；支持 NetBox 分页信封解包

**CLI 指令（Python SDK 验证）：**
```python
from olav.platform.services.response_extractor import auto_extract, truncate_list

# 截断测试
data = [{'id': i} for i in range(100)]
result = truncate_list(data, max_items=5)
# → 6 items (5 + sentinel), sentinel['_truncated'] == True, total_available == 100

# 信封解包
env = {'count': 2, 'next': None, 'results': [{'id':1,'name':'sw1'},{'id':2,'name':'sw2'}]}
result = auto_extract(env, 'netbox', 'GET', '/api/dcim/devices/')
# → {'count': 2, 'next': None, 'results': [{'id':1,'name':'sw1'},{'id':2,'name':'sw2'}]}
```
**实际输出：**
```
truncate_list(100 items, max=5): 6 items, sentinel=True
  total_available=100, returned=5
envelope unwrap: count=2, items preserved intact ✓
```
**状态：** ✅ Verified 2026-04-02
**落地版本：** v0.12.0

### GAP-04: response_extractor — 显式 response_def 字段过滤

**Claim：** 传入 `response_def` 时，service_call 响应按 schema 裁剪未知字段

**CLI 指令（Python SDK 验证）：**
```python
from olav.platform.services.response_extractor import auto_extract
from unittest.mock import patch

data = [{'id':1,'name':'sw1','_noise':'x'}]
with patch('olav.core.api_registry.field_names', return_value={'id','name'}):
    result = auto_extract(data, 'netbox', 'GET', '/api/dcim/devices/', response_def='Device')
# → [{'id': 1, 'name': 'sw1'}]
```
**状态：** ✅ Verified 2026-04-02
**落地版本：** v0.12.0
