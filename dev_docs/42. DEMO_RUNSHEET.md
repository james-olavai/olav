## Chapter 1: Fresh Install — Zero to Web UI in 5 Minutes

**Goal:** Install → 自动建用户 → Web 登录 → 首次查询。

### Step 1: Clean environment

```bash
mkdir ~/olav-demo && cd ~/olav-demo
python3 -m venv .venv && source .venv/bin/activate
```

### Step 2: Install OLAV (~150s)

```bash
pip install olav==0.18.0
```

### Step 3: Initialize

```bash
olav init
```

Expected output:
```
platform ready: created .olav scaffolding
llm: ⚠ unavailable (no API key — edit .olav/config/api.json)
db: ✓ domain.duckdb + audit.duckdb ready
workspace: ✓ core workspace deployed
embedder: ✓ BAAI/bge-small-zh-v1.5 downloaded    ← 首次运行下载 ~50MB
indexes: ✓ router(0 agents), memory(ready)
auth: ✓ admin user 'yhvh' created
  token → ~/.olav/token (chmod 600)
  web login: http://<your-ip>:2280/?token=olav_xxx
registry: ✓ 1 agents registered: core
```

### Step 4: Configure LLM API key

**方法 A：从开发环境拷贝配置**（推荐，保留所有设置）

```bash
# 从开发环境拷贝完整 api.json（含 LLM key、model、embedding 等）
cp /path/to/dev-env/.olav/config/api.json .olav/config/api.json
```

**方法 B：手动编辑**

```bash
nano .olav/config/api.json
```

必填字段：
```json
{
  "shared": {
    "api_key": "sk-or-v1-your-openrouter-key"
  },
  "llm": {
    "model": "x-ai/grok-4.1-fast",
    "base_url": "https://openrouter.ai/api/v1"
  },
  "embedding": {
    "mode": "local"
  },
  "auth": {
    "mode": "token"
  },
  "security": {
    "allowed_cidrs": ["192.168.100.0/24", "127.0.0.1/32"]
  }
}
```

> **配置说明：**
>
> | 字段 | 说明 | 默认值 |
> |---|---|---|
> | `shared.api_key` | LLM API key（OpenRouter/OpenAI/Anthropic） | 空（必填） |
> | `llm.model` | 模型名 | `gpt-4o` |
> | `llm.base_url` | API 端点（OpenRouter 用 `https://openrouter.ai/api/v1`） | OpenAI 默认 |
> | `embedding.mode` | `"local"`（本地 HuggingFace）或 `"api"`（OpenAI embedding） | `"local"` |
> | `auth.mode` | `"none"`（无认证）或 `"token"`（token 登录） | `"none"` |
> | `security.allowed_cidrs` | 允许访问 Web API 的 IP 段（空=放行所有） | 空（全放行） |
>
> **注意：**
> - `embedding.mode` 应为 `"local"`。如设为 `"api"` 且 key 是 OpenRouter，semantic routing 会 401
> - `security.allowed_cidrs` 不配则所有 IP 可访问；`127.0.0.1` 和 `::1` 始终放行；`/health` 端点不受限制
> - `auth.mode=token` 时浏览器访问需要 token（`cat ~/.olav/token`）；`auth.mode=none` 无需登录

### Step 5: Start services

```bash
olav service start --all
```

### Step 6: Web 登录

**获取 token：**
```bash
cat ~/.olav/token
# 输出: olav_xxxxxxxxxxxxx
```

**浏览器访问：**
- 方式 A：直接带 token URL — `http://<your-ip>:2280/?token=olav_xxx`
- 方式 B：打开 `http://<your-ip>:2280` → `/login` 页面 → 粘贴 token

> **注意：** 使用真实 IP（`hostname -I | awk '{print $1}'`），不要用 `localhost`（从其他机器无法访问）。`auth.mode=token` 时 HTTP 下 cookie 正常工作（`secure` 标志已改为动态判断）。

## Chapter 2: Network Discovery — SSH Collection Pipeline

**Goal:** 从零数据到全网采集。

### Step 1: Configure device inventory

**方法 A：从开发环境拷贝**（推荐，保留已验证的设备列表和凭证）

```bash

   .olav/workspace/ops/probe/config/nornir/hosts.yaml

   .olav/workspace/ops/probe/config/nornir/defaults.yaml

# 拷贝 groups（如果开发环境有自定义 group）
cp /path/to/dev-env/.olav/workspace/ops/probe/config/nornir/groups.yaml \
   .olav/workspace/ops/probe/config/nornir/groups.yaml
```

**方法 B：从 example 新建**

```bash
# 设备清单
cp .olav/workspace/ops/probe/config/nornir/hosts.yaml.example \
   .olav/workspace/ops/probe/config/nornir/hosts.yaml
nano .olav/workspace/ops/probe/config/nornir/hosts.yaml
# 填入设备 IP、平台、group（参考 example 中的 6 台设备格式）

   .olav/workspace/ops/probe/config/nornir/defaults.yaml
chmod 600 .olav/workspace/ops/probe/config/nornir/defaults.yaml
nano .olav/workspace/ops/probe/config/nornir/defaults.yaml
# 填入 SSH username 和 password
```

```yaml

connection_options:

    extras:
```

> **安全提示：** `defaults.yaml` 和 `hosts.yaml` 已被 `.gitignore` 排除，不会被提交。`chmod 600` 限制文件权限。

## Chapter 9: Write Security — Multi-Layer Enforcement

**Goal:** 7 层独立安全防线。

```bash
# Layer 1: readonly service — permanently blocked
olav --agent infra "Write to InfluxDB"
# → hard_block: readonly_only=true

# Layer 2: API write — blocked by default
olav --agent infra "Update R1 in NetBox"
# → blocked: pass --enable-api-write

# Layer 3: HITL approval
olav --agent infra "Update R1 in NetBox" --enable-api-write
# → Approve? [y/N]

# Layer 4: SSH write — hard block
olav --agent ops "Push BGP config to R1"
# → hard_block: SSH write not supported

# Layer 5: Sandbox network isolation
olav --agent ops "Use run_python_simulation to POST to http://192.168.100.101"
# → hard_block: outbound network blocked in sandbox
```
