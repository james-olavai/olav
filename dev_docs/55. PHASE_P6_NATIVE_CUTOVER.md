## 0. 为什么重启 P6

`dev_docs/53 §10` 记录了 P6 阻塞：`deepagents-cli._scaffold_workspace`
硬编码 `graph_ref="./server_graph.py:graph"`，忽略我们的 langgraph.json。

当时选择 §10.5 option C（"放弃 native，发 v0.20.2 infra-only"）因为：
1. option A（monkey-patch）被定性"fragile"
2. option B（upstream PR）时间不可控
3. option D（fork）代价过高

本 phase 回到 option A。几个新发现降低了风险评估：

1. **subprocess 用 sys.executable + `-m langgraph_cli dev`** —— 和主进程
   共用 venv，所以 OLAV 已经在 PYTHONPATH 里，不需要额外安装步骤。

2. **langgraph-cli 接受模块路径格式** —— `"olav.server.graph_factory:graph"`
   通过 `langgraph validate` 验证（本 session 实测 `exit 0`）。
   不需要文件路径 hackery。

3. **Monkey-patch 模式 OLAV 已经有** —— `tui_overlay` 的 5 个 patch
   都在生产用。多加一个，套一样的 version guard。

换句话说：option A 的实际复杂度比 §10.5 预估的低。值得试。

## 1. 目标

1. `OLAV_TUI_MODE=native olav` —— TUI 启动时走 `server_kwargs=...`，
   subprocess 加载 OLAV 的 graph_factory，原生 `/agents` 切换真的能
   切到 OLAV agent（ops / audit / topology / command_learner）。
2. `OLAV_TUI_MODE=overlay olav` —— 保留 v0.19.x 覆盖路径作为 rollback。
3. 缺省 auto-detect：new layout + `langgraph_cli` 可用 → native；
   legacy layout 或失败 → overlay.
4. Monkey-patch 版本-guarded；deepagents-cli 升级后不匹配时自动回落
   overlay。
5. 不删任何旧代码 —— overlay 路径保留 for v0.21.x 观察。

## 2. 非目标

- 不改 `olav init` 写入的布局（仍默认 legacy `.olav/workspace/`）
- 不删 `AuditCallbackPlugin`
- 不做 overlay 的 bulk-trim（`/workspace` handler 仍在）
- 不改 netops 的 command_learner（数据问题独立）

## 3. 设计

### 3.1 Monkey-patch 点

**目标 1**：`deepagents_cli.server_manager._scaffold_workspace`
  - 作用：写 tmp work_dir 里的 `langgraph.json`
  - 原始行为：`graph_ref="./server_graph.py:graph"`
  - 我们的行为：额外调用 `generate_langgraph_json` 覆写
    `graph_ref="olav.server.graph_factory:graph"`

```python
def _patch_scaffold_for_olav_graph() -> bool:
    from deepagents_cli import server_manager as _sm
    from deepagents_cli.server import generate_langgraph_json

    if not hasattr(_sm, "_scaffold_workspace"):
        return False

    original = _sm._scaffold_workspace

    def _olav_scaffold(work_dir):
        original(work_dir)
        # Overwrite langgraph.json so subprocess loads OLAV's graph
        generate_langgraph_json(
            work_dir,
            graph_ref="olav.server.graph_factory:graph",
            checkpointer_path="./checkpointer.py:create_checkpointer",
        )

    _sm._scaffold_workspace = _olav_scaffold
    return True
```

加到 `tui_overlay.apply_olav_overlay()` 的 patch chain 里，用同样的
版本 guard (`_SUPPORTED_VERSIONS`).

### 3.2 `simple_cli` 分派

```python
async def simple_cli(agent, assistant_id, session_state, backend, ...):
    apply_olav_overlay()  # includes the new scaffold patch

    mode = resolve_tui_mode()
    if mode == "native":
        try:
            await _run_native(assistant_id, session_state)
            return
        except Exception as exc:
            logger.warning("native TUI failed (%s); falling back to overlay", exc)
    # Overlay path (legacy / fallback)
    await _run_overlay(agent, assistant_id, session_state, backend)
```

`_run_native`:
```python
from deepagents_cli.app import run_textual_app
await run_textual_app(
    server_kwargs={
        "assistant_id": assistant_id,
        "auto_approve": session_state.auto_approve,
        "no_mcp": True,  # MCP integration deferred
        "enable_shell": True,
        "interactive": True,
    },
    ...
)
```

`_run_overlay`: current behaviour (unchanged).

### 3.3 回退路径

| 条件 | 行为 |
|---|---|
| `OLAV_TUI_MODE=overlay`（显式） | 直接走 overlay，不尝试 native |
| `OLAV_TUI_MODE=native`（显式） | 强制 native，失败即 hard error（不回落） |
| 未设（auto） | 默认 native；失败时回落 overlay + warning log |
| `langgraph_cli` 不可 import | auto 模式下 overlay；native 模式下 hard error |
| `_scaffold_workspace` 接口变了（deepagents 升级）| version guard 失败 → monkey-patch 不应用 → subprocess 跑默认 graph，**不是** OLAV 的；需要用 overlay 代替 |

## 5. 风险

| 风险 | 缓解 |
|---|---|
| deepagents 未来重构 `_scaffold_workspace` 函数签名 | version guard + 逐 patch 存在性检查 |
| OLAV 的 plugin_registry 在 subprocess 重构时加载失败 | `graph_factory.build_graph` 已处理 `FileNotFoundError` / `KeyError`；P5 集成测试覆盖 |
| LocalShellBackend 跨 subprocess 失效 | OLAV 的 backend 在 create_olav_agent_with_backend 中可选；失败时回落 `FilesystemBackend` |
| MCP servers mis-config | `no_mcp: True` 在 server_kwargs 里禁掉 |
| 用户无 LLM key | subprocess 启动失败 → failsafe 回落 overlay |
