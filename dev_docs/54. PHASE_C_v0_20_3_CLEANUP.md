## 1. 目标

用户可见：
- `olav skill install` 打 error exit 1，提示 `olav agent install`
- `olav` 默认走 middleware 模式（audit 事件来自 `AuditMiddleware`）
- `OLAV_MIDDLEWARE_MODE=callback` 可 opt-out 回旧行为
- 新增 `olav migrate` 仍存在；底层逻辑不变

开发者可见：
- 3 个散落的 workspace-scan 实现合并为一个 helper
- 7+ 个 CLI 命令统一走 `parse_subcommand_args`
- 测试覆盖面从 ~5.4% 的 CLI verbs 扩到 ~50%（每个 verb 至少一个 smoke test）

## 2. 非目标

- 不触碰 TUI 路径（overlay → native 的 cutover）
- 不删 `AuditCallbackPlugin` 文件（用户仍可 opt-in 回 callback 模式）
- 不删 `skill.py` 整体（`agent_install` 的底层仍依赖 `SkillCommand._install`；改动只在 CLI verb 层）
- 不修 `olav init` 初始化到新 layout（等 P6 恢复再做）
