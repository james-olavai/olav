## 2. DeepAgents：workspace → PyPI 迁移

### 2.1 pyproject.toml 改动

```toml
# 删除:
[tool.uv.workspace]
members = [
    "_legacy_archived/archive_v0_to_v0.11/deepagents/libs/deepagents",
    "_legacy_archived/archive_v0_to_v0.11/deepagents/libs/deepagents-cli",
]

[tool.uv.sources]
deepagents = { workspace = true }
deepagents-cli = { workspace = true }

# 改为（在 dependencies 中）:
"deepagents>=0.4.12,<1.0",
"deepagents-cli>=0.0.34,<1.0",
```

版本约束策略：`>=0.4.12,<1.0`
- 下限：锁定已知可用 API（SummarizationMiddleware 等新特性）
- 上限：1.0 可能有 breaking changes，强制人工评估
- 不 pin 到 `==`：允许 patch 更新（安全修复自动获得）

### 2.2 agent.py 当前 deepagents 调用点

```python
# 当前直接调用（共 4 处）
from deepagents import create_deep_agent
from deepagents.middleware.subagents import CompiledSubAgent, SubAgent
from langchain.agents import create_agent          # subagent 编译
from langchain.agents.middleware import TodoListMiddleware

# create_deep_agent 调用签名（当前使用）
self.graph = create_deep_agent(
    model=self.llm,
    tools=orchestrator_tools,
    system_prompt=...,
    checkpointer=self.checkpointer,
    store=self.store,
    subagents=subagents,
    middleware=...,
)
```

0.4.12 的 `create_deep_agent` 新增了 `skills=` 和 `memory=` 参数，均默认 `None`，
**向后兼容，agent.py 无需修改当前调用**。

## 3. DeepAgents 0.4.12 新特性评估

### 3.1 `SummarizationMiddleware` — 直接解决 Hermes 借鉴计划项

0.4.x `create_deep_agent` 默认栈中加入了 `SummarizationMiddleware`：
- 上下文超过 85% 时自动压缩（先裁剪旧 tool results，再 LLM 摘要中间部分）
- 与 `dev_docs/30. HERMES_ANALYSIS.md §3.6` 规划的功能完全等价
- **无需自己实现，直接得到**

影响：升级后长会话行为改变（之前无压缩，现在有）。验证方式：
```bash
pytest tests/ -m "not e2e and not llm" -k "agent"
# 再跑一次长对话集成测试，确认摘要不丢失关键上下文
```

### 3.2 `MemoryMiddleware` / `SkillsMiddleware` — 可替换 Olav 手动实现

| 0.4.12 组件 | 做什么 | Olav 当前对应代码 | 是否值得替换 |
|------------|--------|-----------------|------------|
| `MemoryMiddleware` | 从 backend 加载 AGENTS.md 注入 system prompt | `_load_olav_config()` 手动 frontmatter 解析 | 暂不替换（Olav 的逻辑更复杂，含 env var 展开和 static_context 注入） |
| `SkillsMiddleware` | SKILL.md 渐进式按需加载 | `_build_subagents()` 预编译所有 subagent | 暂不替换（预编译防止 FilesystemMiddleware 注入，是刻意设计） |

**结论**: 这两个保持当前实现；`SummarizationMiddleware` 直接采用。

### 3.3 `AnthropicPromptCachingMiddleware` — 默认注入

0.4.x `create_deep_agent` 对所有支持 Anthropic 的 LLM 自动加 prompt cache 标记。
当前 Olav 用 OpenRouter (`x-ai/grok-4.1-fast`)，不是 Anthropic，无影响。
切换到 Claude 时自动生效，**无需额外配置**。

### 3.4 `LocalShellBackend` — 与 16 号文档执行后端设计对应

0.4.12 新增的 `LocalShellBackend` 是 Hermes `tools/environments/local.py` 的等价物。
可以作为 `dev_docs/archive/19. SERVICE_REGISTRY_DESIGN.md §3.1` 执行后端抽象的 local 实现基础，
而非从零实现 `src/olav/platform/execution/local.py`。

## 4. 无缝升级策略

### 4.1 问题本质

`agent.py` 直接 `from deepagents import ...`。每次 deepagents 有 breaking change，
Olav 要改 agent.py。隔离层能让升级只发生在一个地方。

### 4.2 Bridge 模块模式

在 `src/olav/agents/_deepagents_bridge.py` 集中所有 deepagents 导入：

```python
"""
_deepagents_bridge.py — deepagents API 的版本隔离层。

升级 deepagents 时只需改这一个文件。
agent.py 从这里导入，不直接接触 deepagents 包。
"""
from importlib.metadata import version as _pkg_version
from packaging.version import Version as V

_DA_VERSION = V(_pkg_version("deepagents"))
_DA_MIN = V("0.4.12")
_DA_NEXT_MAJOR = V("1.0.0")

if _DA_VERSION < _DA_MIN:
    raise ImportError(
        f"deepagents {_DA_VERSION} is too old. "
        f"Olav requires deepagents>={_DA_MIN}. Run: pip install -U deepagents"
    )
if _DA_VERSION >= _DA_NEXT_MAJOR:
    import warnings
    warnings.warn(
        f"deepagents {_DA_VERSION} may have breaking changes. "
        "Verify compatibility before using in production.",
        stacklevel=2,
    )

# ── Core exports (stable across 0.4.x) ──────────────────────────────────
from deepagents import create_deep_agent as _create_deep_agent
from deepagents.middleware.subagents import CompiledSubAgent, SubAgent

# ── Version-gated features ───────────────────────────────────────────────
HAS_SUMMARIZATION = _DA_VERSION >= V("0.4.0")
HAS_LOCAL_SHELL_BACKEND = _DA_VERSION >= V("0.4.0")
HAS_NAMESPACE_FACTORY = _DA_VERSION >= V("0.4.0")

if HAS_SUMMARIZATION:
    from deepagents.middleware import SummarizationMiddleware
else:
    SummarizationMiddleware = None  # type: ignore[assignment,misc]

if HAS_LOCAL_SHELL_BACKEND:
    from deepagents.backends import LocalShellBackend
else:
    LocalShellBackend = None  # type: ignore[assignment,misc]


def create_deep_agent(**kwargs):
    """Stable wrapper around deepagents.create_deep_agent.

    Normalises keyword argument names if the upstream API changes.
    Current 0.4.x signature is stable; this wrapper adds a future-proof
    shim point without touching agent.py.
    """
    return _create_deep_agent(**kwargs)


__all__ = [
    "create_deep_agent",
    "CompiledSubAgent",
    "SubAgent",
    "SummarizationMiddleware",
    "LocalShellBackend",
    "HAS_SUMMARIZATION",
    "HAS_LOCAL_SHELL_BACKEND",
    "HAS_NAMESPACE_FACTORY",
    "_DA_VERSION",
]
```

`agent.py` 改为从 bridge 导入：
```python
# 修改前
from deepagents import create_deep_agent
from deepagents.middleware.subagents import CompiledSubAgent, SubAgent

# 修改后
from olav.agents._deepagents_bridge import (
    create_deep_agent,
    CompiledSubAgent,
    SubAgent,
    SummarizationMiddleware,
)
```

### 4.3 升级时的操作流程

```bash
# Step 1: 更新依赖
uv add "deepagents>=X.Y.Z,<NEXT_MAJOR"

# Step 2: 运行兼容性检查（自动）
python -c "from olav.agents._deepagents_bridge import _DA_VERSION; print('deepagents', _DA_VERSION)"
# 如果有 warning/error，Bridge 模块会提示需要处理

# Step 3: 只改 _deepagents_bridge.py
# - 更新 _DA_MIN 下限
# - 添加新的 version-gated feature exports
# - 如果有 API 重命名，在 create_deep_agent() wrapper 里做 kwarg 映射

# Step 4: 运行快速验证
pytest tests/unit/test_agent_bridge.py -v
pytest tests/ -m "not e2e and not llm and not network" --tb=short

# Step 5: 更新 pyproject.toml 版本约束
```

### 4.4 Bridge 模块的测试

```python
# tests/unit/test_agent_bridge.py

def test_bridge_imports_cleanly():
    from olav.agents._deepagents_bridge import (
        create_deep_agent, CompiledSubAgent, SubAgent, _DA_VERSION
    )
    assert create_deep_agent is not None
    assert _DA_VERSION is not None

def test_version_requirement_met():
    from olav.agents._deepagents_bridge import _DA_VERSION, _DA_MIN
    assert _DA_VERSION >= _DA_MIN, f"deepagents {_DA_VERSION} < required {_DA_MIN}"

def test_feature_flags_coherent():
    from olav.agents._deepagents_bridge import (
        HAS_SUMMARIZATION, SummarizationMiddleware
    )
    if HAS_SUMMARIZATION:
        assert SummarizationMiddleware is not None
    else:
        assert SummarizationMiddleware is None

def test_create_deep_agent_signature():
    """确认 wrapper 接受当前已知的 kwargs。"""
    import inspect
    from olav.agents._deepagents_bridge import create_deep_agent
    # wrapper 用 **kwargs，不做签名检查，确认可调用即可
    assert callable(create_deep_agent)
```

## 6. 版本策略

```
0.12.0   平台基础 + deepagents PyPI 化（本次发布目标）
0.13.0   Service Registry（dev_docs/15 实现）
0.14.0   旁路安全监控 LLM（SecuritySidecarPlugin）
1.0.0    稳定 API + 完整企业功能 + SLA 承诺
```

语义版本约定：
- `0.x.0`：minor，可能有向前不兼容的内部 API 变更（platform 协议稳定）
- `0.x.y`：patch，仅 bug fix 和安全更新
- `1.0.0`：公开 API 冻结，SemVer 严格遵守
