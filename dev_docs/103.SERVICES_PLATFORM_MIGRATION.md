## Open sub-decision (ADR-0014 Decision 4)

`devops` destination is the least-settled point. Default = platform
(olav), because script generation is generic and netops is scoped to
netops+audit. If `devops`'s NetBox/InfluxDB integrations are judged
network-specific, the alternative is to dissolve devops (script-gen →
core, infra queries → services) rather than move it wholesale. Confirm
before Phase B.
