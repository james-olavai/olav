## 0. 阅读指南

本文档是 **可执行实施清单**，不是设计讨论。

- 设计原理与 finding 见 `00. issues.md` 对应 ARCH-NN 条目
- 本文聚焦 **"先写测试 → 再改代码 → CI 永久守护"** 的工作序列
- 每个任务按 **TDD 三步**：① Red（写失败测试）② Green（最小修复让测试过）③ Refactor + CI 集成

**全局原则:**
- 不写测试不改代码
- 单 PR 单任务（任务粒度见各小节）
- CI Tier-0 必须永远绿；新加测试必须分到合适 Tier

```python
    assert cfg.context_budget == 8000
```

**Green — 实现:**
1. `src/olav/core/config.py` 新增 `MODEL_TIER_REGISTRY`：
   ```python

       # 模式匹配 → tier 映射
       r"qwen.*-8b|llama.*-8b|.*-3b|.*-1\.5b": "small",
       r".*-32b|.*-70b|sonnet|haiku": "medium",
       r"opus|.*-405b": "large",

       "small":  {"context_budget": 8000,   "recall.top_k": 1, "static_context_modes": {"always"}},
   ```

2. `ConfigLoader` 加 `resolve_model_tier(model_name) -> tier`
3. 所有现有读取 `RECALL_TOP_K` / 默认 LIMIT 的位置改读 tier-aware 配置

```python
    for tool in CRITICAL_TOOLS:
        # 只允许：vendored (src/olav/data/workspace) + 部署目录 (.olav/workspace) symlink 各 1
```
