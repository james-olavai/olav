# OLAV Knowledge Base

Platform-wide curated knowledge. Any file format accepted (PDF, DOCX, Markdown, TXT, HTML, CSV).

Import into OLAV memory: `olav kb import-kb`

## Structure
- `network/` — BGP/OSPF/topology rules, vendor quirks
- `platform/` — OLAV operational conventions
- `integrations/` — NetBox, Grafana, InfluxDB API guides
- `audit/` — Audit Profile authoring conventions
