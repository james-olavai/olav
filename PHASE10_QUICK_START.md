## 📞 Troubleshooting

**Issue**: "ModuleNotFoundError: No module named 'langchain_openai'"
```
Solution: uv pip install langchain-openai
```

**Issue**: "LLM API Error"
```
Solution: Check .env LLM_API_KEY and LLM_BASE_URL are correct
Falls back to mock recommendations automatically
```

**Issue**: "Cannot find devices"
```
Solution: Verify .olav/config/nornir/hosts.yaml has devices
```
